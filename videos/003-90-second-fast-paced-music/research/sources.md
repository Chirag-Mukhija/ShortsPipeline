## Self-check of the capacity arithmetic (by hand, from [5] and [6])
- 40-L data capacity: 2,956 codewords x 8 = 23,648 bits.
- Numeric: 4 (mode) + 14 (count) + 2,363 groups of 3 digits x 10 bits (23,630) = 23,648. 7,089 = 2,363 x 3. Fits to the bit.
- Byte: 4 + 16 + 2,953 x 8 (23,624) = 23,644; the last 4 bits are the terminator = 23,648. Fits.
- Total codewords at 40-L: 2,956 + 25 x 30 = 3,706; data-area modules 3,706 x 8 = 29,648; grid 177 x 177 = 31,329; difference 1,681 modules = function patterns and format/version info (remainder bits for version 40 = 0: from the standard's table, from memory, not read).
