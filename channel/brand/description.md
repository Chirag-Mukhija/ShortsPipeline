# Channel description

Paste the text between the lines into YouTube Studio → Customization → Basic info → Description (limit 1,000 characters; this is about 640).

---
I'm Chirag, a student from India figuring out tech in the age of AI, by actually building things.

AI can write code now. So what's still worth learning, and how do you learn it without drowning in tutorials? This channel is my answer, tested on myself: real projects, real mistakes, and what I'd tell a friend who's starting today.

What you'll find here:

• Things I build from scratch, including the AI video studio that helps me make this channel

No hype, no "master it in 7 days". Just one student building in public.

Subscribe if you want to learn alongside me.

## Uploading the images
| File | Where in YouTube Studio | Notes |
|---|---|---|
| `logo.png` (800×800) | Customization → Branding → Picture | Shown as a circle; the design is built for that |
| `banner.png` (2048×1152) | Customization → Branding → Banner image | The name and tagline sit inside the safe area every device shows |
| `watermark.png` (300×300) | Customization → Branding → Video watermark | Choose "End of video" or "Entire video" |

To change the name or tagline: edit `NAME` and `TAGLINE` at the top of the script in `brand.html`, then run `sh render.sh` in this folder.
